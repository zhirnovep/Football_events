# ⚽ Сбор на футбол

Сайт для сбора на футбол вместо телеграм-бота. Работает по ссылке, не зависит от мессенджера. Каждый заходит один раз, выбирает себя из списка — устройство его запомнит.

## Что нужно (всё бесплатно на вашем масштабе)

- Аккаунт на [supabase.com](https://supabase.com) — база данных
- Аккаунт на [vercel.com](https://vercel.com) — хостинг сайта
- Аккаунт на [github.com](https://github.com) — чтобы Vercel мог забрать код

Займёт минут 20–30 в первый раз.

## Шаг 1. Supabase (база данных)

1. Зайдите на supabase.com → **New project**. Придумайте пароль от базы (сохраните куда-нибудь).
2. Когда проект создан — слева меню **SQL Editor** → **New query**.
3. Откройте файл `supabase-schema.sql` из этого проекта, скопируйте всё содержимое, вставьте в редактор и нажмите **Run**.
4. Слева **Project Settings → API**. Скопируйте:
   - **Project URL**
   - **anon public** ключ

Это два значения, которые понадобятся дальше.

## Шаг 2. Заполните список друзей

Слева **Table Editor → roster**. Нажмите **Insert row** и добавьте имена всех, кто обычно ходит на футбол (можно и позже, люди умеют добавлять себя сами, если их нет в списке — это просто ускорит первый запуск).

## Шаг 3. Локальный запуск (проверить, что всё работает)

Понадобится [Node.js](https://nodejs.org) (18 версии или новее).

```bash
cd football-sbor-app
npm install
cp .env.example .env
```

Откройте `.env` и вставьте туда ваши значения из Шага 1:

```
VITE_SUPABASE_URL=https://ваш-проект.supabase.co
VITE_SUPABASE_ANON_KEY=ваш-anon-ключ
```

Запустите:

```bash
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`) — должна открыться страница сбора.

## Шаг 4. Выложить на GitHub

```bash
git init
git add .
git commit -m "Первый коммит"
```

Создайте пустой репозиторий на github.com, затем:

```bash
git remote add origin https://github.com/ваш-логин/football-sbor.git
git branch -M main
git push -u origin main
```

Файл `.env` в репозиторий не попадёт — он в `.gitignore`, это правильно, ключи туда попадать не должны.

## Шаг 5. Деплой на Vercel

1. Зайдите на vercel.com → **Add New → Project** → выберите репозиторий `football-sbor`.
2. Vercel сам определит, что это Vite-проект — ничего менять не нужно.
3. Перед деплоем откройте **Environment Variables** и добавьте те же две переменные:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. Нажмите **Deploy**.

Через минуту получите ссылку вида `football-sbor.vercel.app` — это и есть ваш сайт. Скиньте её в любой чат (Телеграм, Макс, куда угодно).

## Как этим пользоваться

- **Первый заход**: каждый выбирает своё имя из списка или добавляет себя, если его там нет. Дальше устройство запоминает выбор.
- **Организатор** создаёт сбор (название, сколько человек нужно).
- Все отмечаются: Иду / Не иду / Думаю, плюсуют гостей.
- Когда сбор набрался — любой может нажать **Закрыть сбор**, после чего появляются кнопки отметки оплаты (за себя и за каждого гостя отдельно).
- **Начать новый сбор** стирает текущий и открывает форму создания нового — используйте перед следующей игрой.

## Если хочется большего

Возможные доработки под ваш случай:
- PIN-код на человека, чтобы никто случайно не отметился чужим именем
- История прошлых сборов вместо одного активного
- Общая сумма к оплате (аренда / кол-во человек) с автоматическим расчётом на каждого
- Push-уведомление организатору, когда набралось нужное количество человек

Если что-то из этого понадобится — можно дописать отдельно.
